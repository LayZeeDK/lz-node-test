# lz-node-test

An Nx workspace with three ESM-only packages for Node.js 22.18 or later:

- `@layzee/stryker-node-test-runner`: a StrykerJS test runner for `node:test`.
- `@layzee/stryker-node-test-mutators`: StrykerJS mutators for Node.js APIs.
- `@layzee/lz-node-test`: `testEach` and `testFor` table-test helpers for `node:test`.

The packages are empty. Their code arrives in a later commit.

Each package has its own README. The MIT license is in `LICENSE`.
